소리 없음

네 가지 표현 모드

v2.0에 담긴 것

7.1 채널까지 방향 인식

스테레오, 5.1, 7.1 출력 구성을 자동으로 알아보고 각 채널을 제자리에 그립니다. 출력 장치가 바뀌면 그 장치에 맞춰집니다.

AI 소리 분류

소리를 환경음, 대화음, 위협음으로 나눠 색으로 보여 줍니다. 5.1, 7.1 환경에서는 뒤쪽과 옆쪽 채널의 소리도 AI가 듣습니다.

네 가지 표현 모드

파도, 패드, 원형, 외곽선 가운데 선택합니다. 30 FPS부터 모니터 주사율까지, 최대 프레임을 얼마로 두어도 그림이 같은 빠르기로 움직입니다.

보던 화면을 내리지 않는 단축키

F2로 사운드 모드, F3로 표현 모드를 바로 바꿉니다. 단축키는 설정 탭에서 원하는 키 조합으로 바꿀 수 있습니다.

편집 모드

F4를 누르면 화면에 경계선이 나타나고, 끌어서 그려지는 영역의 크기와 한계를 조절합니다. 색과 진하기도 패널에서 바로 바꿉니다.

소리마다 종류 정하기

AI가 알아듣는 소리 521개를 Android 버전과 같은 묶음으로 보여 주고, 묶음마다 어느 종류로 볼지 선택합니다.

키보드와 화면 읽어주기

런처의 모든 칸에 Tab 키로 닿고, Ctrl + Tab으로 탭을 옮기며, Esc로 창을 닫습니다. 내레이터와 NVDA가 버튼과 상태를 읽어 줍니다.

튜토리얼과 18개 언어

처음 열면 실제 그리기 엔진으로 쓰는 법을 보여 줍니다. 처음에는 Windows 표시 언어를 따릅니다.

설치 없이 바로 실행

.NET을 따로 설치하지 않아도 됩니다.

ZIP 받기

  1. GitHub Releases에서 SoundVisualizer_v2.0.zip을 받아 원하는 곳에 압축을 풉니다.
  2. 폴더 안의 SoundVisualizer.exe를 실행합니다.
  3. Windows의 PC 보호 창이 뜨면 추가 정보를 누른 뒤 실행을 누릅니다.
  4. 런처에서 언어와 초기 설정을 마친 뒤 실행을 누르면 오버레이가 켜집니다.
  5. 설정은 실행 파일 옆 settings.json에 저장되므로, 폴더를 그대로 옮겨도 됩니다.

Windows 앱 질문

  • 5.1, 7.1 채널로 출력하면 앞뒤와 옆까지 구분합니다. 스테레오 출력은 왼쪽과 오른쪽만 구분하고, 좌우에 함께 있는 소리는 화면 위쪽에 그립니다.

  • 독점 전체 화면 모드로 도는 앱이라면 테두리 없는 창 모드나 창 모드로 바꿔 보세요. 소리가 Windows 기본 출력 장치로 나오고 있는지도 확인해 주세요.

  • 앱 안이나 Windows 볼륨 믹서에서 그 앱의 볼륨을 아주 낮추거나 음소거하면 소리가 거의 보이지 않을 수 있습니다. 소리를 조금 키우거나 설정 탭에서 민감도를 올려 보세요.

  • 네. 런처의 모든 칸에 Tab 키로 닿고, Ctrl + Tab으로 다음 탭으로 갑니다. 아이콘 버튼과 소리 목록은 화면 읽어주기가 이름으로 읽고, 마우스로 끄는 값은 패널의 슬라이더로도 바꿀 수 있습니다.

  • 아니요. 압축을 풀고 SoundVisualizer.exe를 실행하면 됩니다.
